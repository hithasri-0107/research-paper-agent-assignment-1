# CS Researcher Agent

An AI-powered research paper analysis application built using Google AI Studio.

## Features
- Research paper URL input
- Research paper summarisation
- Core concept extraction
- System architecture flowcharts using Mermaid.js
- Future research and development opportunities
- Paper metadata extraction
- JSON, TXT and Markdown exports

## Technologies
- React
- TypeScript
- Vite
- Gemini API

## Purpose
Developed as part of the Introduction to Generative AI course assignment.
